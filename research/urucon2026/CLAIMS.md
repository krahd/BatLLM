# Claim-to-evidence ledger

| Claim | Evidence | Boundary |
|---|---|---|
| Full-mode traces reconstruct the ordered request captured immediately before provider invocation. | `research_runtime.py` materialises the provider payload; `trace_verifier.py` independently rebuilds the current user message and conversation history, checks provider/model/endpoint provenance, and verifies the canonical payload commitment. | This verifies the recorded invocation. It does not regenerate the same model response. |
| Response-to-command grounding is independently verifiable when response text is retained. | The verifier re-runs `parse_model_response()` and checks both the normalised command and status. | Redacted and hash-only modes retain commitments but cannot independently parse hidden text. |
| Grounded actions are operatively replayable. | The recorder and verifier invoke `replay_engine.apply_play()` with a frozen `GameplaySettingsSnapshot`; derived states and ordered semantic events are compared with the trace. | The graphical Kivy application retains its v2 export path; the claim is for the v3 research runtime. |
| Trace corruption and semantic inconsistency are detected. | The verifier checks schema, privacy-mode consistency, request provenance, exact request reconstruction, state supplied to the model, sequence, state continuity, final states, commitments, grounding, and replay equivalence. | Ordinary hashes are not authentication. A comprehensive adversarial rewrite requires an external anchor to detect. |
| The evaluation covers every BatLLM command form and invalid text. | `generate_corpus.py` cycles through movement, parameterised movement, both rotations, shield toggle/set, shooting, and invalid free text under varied rules and context modes. | Scripted outputs test trace semantics, not LLM capability. |
| All reference traces reproduce state and semantic events. | `replay-summary.json` is generated from the verifier; CI regenerates and archives the corpus and results. | Numerical timing values are environment-specific. |
| All applicable controlled semantic perturbations are detected after re-anchoring retained content. | `inject_faults.py` mutates eleven fault classes and recomputes every commitment derivable from retained mutated content before verification. | Mutations of text absent under privacy reduction are inapplicable, not counted as detections. |
| The work is distinct from the BatLLM AI-literacy research programme. | The manuscript contains no learning-effect, classroom, bilingual, cross-cultural, or human-subject claim. | Those questions remain available for journal and pedagogical work. |
