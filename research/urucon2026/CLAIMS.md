# Claim-to-evidence ledger

| Claim | Repository evidence | Boundary |
|---|---|---|
| Full-retention traces independently reconstruct the adapter-boundary invocation record passed to the provider adapter. | `research_runtime.py` materialises the invocation before calling the adapter; `trace_verifier.py` independently rebuilds the current user message and history from separately recorded prompt, state, system instructions, and context policy. | This is not transport capture and does not expose provider-library transformations, hidden defaults, weights, or serving binaries. |
| Retained response-to-command grounding is independently verifiable. | The verifier re-runs `parse_model_response()` and checks both the normalised command and validity status. | Redacted and hash-only traces retain commitments but cannot independently parse hidden response text. |
| Grounded actions are operatively replayable. | Recorder and verifier invoke `replay_engine.apply_play()` with a frozen `GameplaySettingsSnapshot`; derived states and ordered semantic events are compared with the trace. | The graphical Kivy application retains its v2 export path; the claim is for the v3 research runtime. |
| Replay is not evaluated solely by calling the production transition function twice. | `reference_semantics.py` independently implements command normalisation and gameplay semantics without importing BatLLM gameplay code; `differential_semantics.py` compares normalisation, states, events, and projectile paths. | Differential agreement is not a proof and cannot exclude common-specification error. |
| Controlled semantic inconsistencies are detected after ordinary commitments are re-anchored. | `inject_faults.py` mutates eleven fault classes, targets early/middle/late positions where applicable, and recomputes every commitment derivable from retained mutated content. | This is fixture-based invariant testing, not an empirical estimate of adversarial detection in deployment. |
| Benign JSON representation changes do not create observed false failures. | `serialization_controls.py` verifies compact ASCII, pretty Unicode, and recursively reversed-key representations of every reference trace. | The control set does not exhaust all possible encoders or schema-preserving transformations. |
| Reference traces reproduce recorded state and semantic events. | `replay-summary.json` is generated by the verifier and regenerated in CI. | Scripted provider output tests trace semantics, not LLM competence or provider fidelity. |
| Storage and verification costs are measured without an arbitrary comparison baseline. | `measure_overhead.py` reports canonical raw and gzip bytes per play by retention profile and median repeated in-memory verification time. | Timing excludes file I/O and JSON parsing and is environment-specific. |
| The work is distinct from BatLLM's AI-literacy and pedagogy programme. | The canonical manuscript makes no learning-effect, classroom, bilingual, cross-cultural, or human-subject claim. | Pedagogical and HCI questions remain available for later journal and empirical work. |
| Hash commitments provide internal consistency, not authentication or confidentiality. | The canonical manuscript in `krahd/academic-writing`, this README, and the audit state the threat boundary explicitly. | Comprehensive replacement remains possible without an external trust anchor; low-entropy committed text may be guessed. |
