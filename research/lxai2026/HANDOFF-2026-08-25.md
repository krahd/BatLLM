## Transport provenance

The original Modelito 1.4.5 Ollama path did not transmit nominal `temperature`, `seed` or `num_predict` settings. The old 360-call dataset and its result summary were deleted.

Modelito commit `0bc829d2766a58e30b17c3822a9d70be9d038219` (`Fix Ollama settings propagation`) fixes the library issue, but this main LXAI run remains direct Ollama throughout to avoid mixing transports.

## Pre-freeze diagnostics

Excluded from the main dataset:

- multiple smoke/debug runs;
- D1 four-state sanity runs;
- manual state-extraction/predicate/branch decomposition;
- manual branch-order control.

Key diagnostic finding: Qwen3 4B and 30B could read state and evaluate a simple threshold but showed an asymmetric false-branch policy-execution failure. Mistral executed both logically equivalent branch-order formulations correctly. Llama 3.2 additionally showed format-following failures in the symbolic probe. These observations motivated prospectively declared state-invariance/branch-position diagnostics, not a post-freeze prompt change.

## Primary interpretation rule

The main inferential comparison is matched `es_standard` vs `es_rioplatense`. English is a secondary reference. D1–D6 absolute accuracy is not by itself a validated measure of reasoning complexity; interpret it with branch/state diagnostics.

Do not claim equivalence from nonsignificance, do not anthropomorphise a higher Rioplatense score, and do not generalise pooled results from these four fixed models to a model population.
